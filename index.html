Me chamo Ricardo

Sou o Ricardo, estudante do 3º período de Engenharia de Software no iCEV, em Teresina. Sou apaixonado por tecnologia e focado em entender como os sistemas operam desde a lógica estrutural até a interface do usuário. Atualmente, aplico minha visão analítica no setor público, atuando na Secretaria de Estado de Saneamento Básico do Piauí (SESB-PI). Dentro da Diretoria de Obras (DTO), lido com especificações e relatórios de projetos que têm impacto social direto. Essa vivência tem me ensinado na prática a importância de alinhar a engenharia às necessidades reais das pessoas. No desenvolvimento de software, venho construindo uma base sólida em tecnologias web (HTML, CSS e JavaScript), Java e banco de dados relacionais (SQL), além de utilizar Git/GitHub para versionamento e colaboração. Meu objetivo é continuar aprimorando minhas habilidades na construção de aplicações eficientes, modernas e que realmente façam a diferença.

Projeto Escalonador de Processos

Este projeto implementa o escalonador de processos do sistema operacional fictício iCEVOS, desenvolvido como parte da disciplina Algoritmos e Estrutura de Dados I. O escalonador é responsável por decidir qual processo terá acesso à CPU em cada ciclo, considerando:
🎯 Listas de prioridade (alta, média e baixa)
🛡️ Prevenção de inanição (starvation)
🔒 Gerenciamento de recursos (processos bloqueados por DISCO)
⚡ Execução em tempo real com logs detalhados
