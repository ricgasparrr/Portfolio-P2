#  Meu Portfólio Pessoal

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido como requisito da atividade "Criação de Portfólio" da disciplina de Programação Web (P2), com o objetivo de centralizar minhas informações profissionais, habilidades e principais projetos de desenvolvimento.

🌐 **[Acesse o Portfólio ao vivo aqui](https://ricgasparrr.github.io/Portfolio-P2/)**

---

##  Objetivo do Projeto
Criar uma página web estática, totalmente responsiva e funcional, para apresentar meu perfil como estudante de Engenharia de Software no iCEV e minha atuação no setor público (SESB-PI), além de servir como vitrine para os códigos que venho desenvolvendo.

## 🛠️ Tecnologias Utilizadas
O projeto foi construído "Vanilla", sem o uso de frameworks externos, para consolidar a base do desenvolvimento web:
* **HTML5:** Estruturação semântica e acessibilidade.
* **CSS3:** Estilização, layout em Flexbox e responsividade via Media Queries.
* **JavaScript:** Lógica de manipulação do DOM.
* **GitHub Pages:** Hospedagem e deploy contínuo.

## ✨ Principais Funcionalidades
* **Alternância de Tema (Dark/Light Mode):** Implementado com JavaScript para alterar as variáveis de cor CSS (CSS Custom Properties) no root do documento.
* **Design Responsivo:** Adaptado para dispositivos móveis, ajustando o menu lateral para uma navegação no topo em telas menores.
* **Navegação Suave (Smooth Scrolling):** Efeito de deslizamento entre as seções implementado puramente com CSS (`scroll-behavior`).

## 📂 O que você vai encontrar no Portfólio
O site está estruturado nas seguintes seções:
1. **Início:** Apresentação e foto de perfil.
2. **Sobre Mim:** Detalhes sobre minha trajetória acadêmica e profissional.
3. **Habilidades:** Hard skills técnicas (HTML, CSS, JS, Java, C, SQL).
4. **Projetos:** Destaque para trabalhos práticos (Projeto Syntax, Escalonador de Processos iCEVOS e Página de Notícias).
5. **Contato:** Links diretos para meu E-mail, GitHub e LinkedIn.
